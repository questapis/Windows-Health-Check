
# 🛡️ Windows Health Check

A sleek Windows desktop tool designed to scan your system, identify performance issues, and help keep your PC running smoothly.

---

## 🚀 Features

- 🔍 **System Scan**
  - View CPU, RAM, storage, and system info at a glance

- 🧠 **Health Score**
  - Quick rating based on performance factors

- 🧹 **Cleanup Tool**
  - Remove non-essential temporary files safely

- ⚡ **Update Tools**
  - Launch app updates and Windows Update in one click

- 🎯 **Performance Tips**
  - Get recommendations based on your hardware

- 🖥️ **Modern UI**
  - Dark / Light mode with a clean blue-accent design  
  - Smooth splash screen with QuestAPIs branding

## 🛠️ Installation

1. Download the `.exe` from the link above  
2. Open the file  
3. If Windows shows a warning:
   - Click **More Info**
   - Click **Run Anyway**

No installation required.
